# Application Web de gestion d'événements

## Présentation
Projet scolaire réalisé dans le cadre du cours 420-15D-FX. Cette application Web permet de gérer des événements et leurs participants.


## Fonctionnalités
- Création, consultation, modification et suppression d'événements (CRUD).
- Gestion des catégories d'événements.
- Authentification des utilisateurs et gestion des rôles.
- Inscription des utilisateurs aux événements.
- Recherche et filtrage des événements.
- Gestion des participations aux événements.
  


## Technologies utilisées
- **C#** : langage de programmation principal.
- **ASP.NET Core 9** : framework de développement Web.
- **Razor Pages** : création des pages et gestion des interactions.
- **Entity Framework Core** : accès et manipulation des données.
- **SQL Server** : base de données relationnelle.
- **ASP.NET Core Identity** : authentification et gestion des utilisateurs.
- **HTML et CSS** : structure et présentation des interfaces.
- **Git et GitHub** : gestion des versions du projet.
  


## Compétences développées
- Développement d'une application Web avec C# et ASP.NET Core.
- Implémentation des opérations CRUD pour gérer les événements et les catégories.
- Utilisation d'Entity Framework Core pour accéder aux données SQL Server.
- Gestion de l'authentification et des rôles avec ASP.NET Core Identity.
- Organisation du code avec Razor Pages et séparation des responsabilités.
- Utilisation de Git et GitHub pour le suivi des versions.
  

## Contexte
Projet réalisé à des fins pédagogiques dans le cadre de mon DEC en Techniques de l'informatique au Cégep Garneau.
